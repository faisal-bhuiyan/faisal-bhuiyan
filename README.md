### About Me

- 🚀 I build high-performance C++ software for computational solid mechanics and computational geometry problems across aerospace and manufacturing applications
- 💼 Most recently at [NREL](https://www.nrel.gov/) as a scientific software developer — top contributor to [Kynema](https://github.com/Exawind/openturbine), a flexible multibody dynamics codebase for simulating wind turbine structural dynamics
- 🌱 Core expertise: C++, HPC, finite element analysis (FEA), parallel and GPU-accelerated computing (Kokkos, currently learning CUDA), and numerical methods for mechanics-based problems
- 🔭 Long-standing interest in the intersection of physics simulation and machine learning — surrogate modeling, physics-informed neural networks (PINNs), and differentiable simulation
- 📚 Academic contributions in computational mechanics on [Google Scholar](https://scholar.google.com/citations?user=v7zm7nYAAAAJ&hl=en&authuser=1)
- 👯 Enthusiastic about collaborating on open-source computational mechanics and computational geometry projects
- 👨‍💻 Explore my projects on [GitHub](https://github.com/faisal-bhuiyan?tab=repositories)
- 💬 Ask me about FEA, flexible multibody dynamics, computational geometry, composite materials, additive manufacturing, or GPU computing
